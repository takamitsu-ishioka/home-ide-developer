# 雑多なメモを保存する場所

## 誰が

- 基本的にユーザー
- ユーザーの指示で、あるいはユーザーの意図を汲んでエージェントが

## 何のために

- ユーザーの思考（抽象から具象まで）を保存するために
- ~/bin/worklog の出力データの欠落を補うために

## 何を

- misc/           画像・PDFなど、雑多な非テキスト素材
- plans/          作業計画書
- raw.md          なんでも「とりあえず」書く
- readme.md       このファイル
- structured.md   raw.md から抽出した「構造化」されたデータを書く

## どうする

- ユーザー: CRUD
- エージェント: CRUD (ただし U と D はユーザーに許可を求める)
